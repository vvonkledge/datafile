# pi-datafile

A [pi package](https://pi.dev) for datafile: Append-only JSONL record store with a runtime YAML contract.

Generated by `datafile.py pi-package`. Do not edit by hand - regenerate instead.
`datafile.py pi-package --check` catches drift, and it is portable: the
generated files carry no path from the machine that generated them, so the same
commit checks clean anywhere, CI included.

## Install

```sh
pi install /path/to/pi-datafile
```

Add `-l` to install into this project's `.pi/settings.json` instead of your
account.

## What it provides

- **skills/datafile/SKILL.md** - loaded on demand when a task involves a
  `.jsonl` store with a YAML contract.
- **extensions/ambient-context.ts** - captures the store overview at
  `session_start` and appends it to the system prompt, so a session opens
  already knowing which stores exist.

The extension runs `datafile` from `PATH`, resolved on the machine the
session runs on. If it is not there, the session opens without ambient context
and the extension prints how to install it; it never reaches for a path from
another machine.

To put `datafile` on `PATH`, run `just install` in the datafile checkout,
or link `datafile.py` onto `PATH` as `datafile` by hand.
